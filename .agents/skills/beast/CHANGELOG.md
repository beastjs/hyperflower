# Changelog

All notable changes to the Beast skill are recorded here.

## [Unreleased]

## [0.12.1] - 2026-10-10

### Changed

- Document the creator’s optional development tools, Beast UI and icon initialization,
  keyboard prompts, and automation/deferred-setup flags.

- Update the README for the Beast/Octane `0.12.1` toolchain, explicit parser
  installation, companion packages, scaffold options, migration behavior, and
  current TypeScript language-server features.

- Align skill version `0.12.1` with Beast compiler, create-beast, and Octane.
- Add the 0.4 through 0.12 migration references, update bundler signal guidance,
  and refresh current coverage and TypeScript language-server capabilities.
- Document direct context providers, revised signal keys and resources,
  writable textarea restoration/reset behavior, and native attribute contracts.

## [0.3.1] - 2026-09-07

### Changed

- Updated the published toolchain references to `beast-tsrx@0.2.60`, `create-beast@0.2.60`, and `octane@0.2.6`.
- Documented project scaffolding with the selected bundler and Octane UI binding.

## [0.3.0] - 2026-08-29

### Added

- Added authoring guidance for setup-bearing and code-only `scope` children.
- Added Vite, Rspack, and Rsbuild guidance for Octane's experimental
  `nativeReads` compiler option.

### Changed

- Updated compatibility and coverage guidance for `beast-tsrx@0.2.9`,
  `octane@0.1.49`, and the `0.1.44` Octane Rspack/Rsbuild plugins.
- Expanded Strong-mode coverage notes to include Effect Event and
  nondeterministic-render diagnostics.
- Documented the project-owned changelog generated by `create-beast@0.2.12`.

Releases through Beast skill `0.2.0` predate this changelog.
